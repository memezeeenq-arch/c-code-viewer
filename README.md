# Minimal C Code Viewer

The nine C programs are extracted from `Practice.docx` and served at `/api/1`
through `/api/9`. Each route displays only the source code for its corresponding
program.

## Run locally

```sh
npm install
npm run dev
```

Open a program URL such as `http://localhost:5173/api/1`. To create and preview
a production build, run `npm run build` and `npm run preview`.
